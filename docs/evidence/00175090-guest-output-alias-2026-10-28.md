# `0x00175090`: verified common guest-stack output alias for three helper calls

**Scope:** one C11 draft stack-output spelling repair. Original register and x86 memory facts are authenticated; the *full C function's* virtual calls, helper ABI, Xbox runtime behavior, and native PC linking remain **ABI_UNVERIFIED**.

## Original machine-code evidence

- XBE original SHA-256 `B6EA5D4DD6500AE86C3F5E3E4618BC9B1E3FACDDCB483170DFEE7A787087C721`.
- `0x00175090`, **523 bytes**, original body SHA-256 `1DE3394F83B1C178827366D655F3A85736F4ACC9C3D2CED9674B501F6FB7C409`.
- Original function prologue: `0x175090 SUB ESP,0x0C`, `PUSH EBX`, `PUSH EDI`; the case-dispatch loop at `0x1750B0` additionally pushes `EBP` and `ESI`.
- Three distinct CALL boundaries each push three outgoing DWORDs and execute `8D 44 24 20` (`LEA EAX,[ESP+0x20]`) to pass **one and the same** four-byte scratch output through the **EAX register**:

| Caller LEA / CALL | Original target | Scratch guest address relative to entry ESP `E` |
| --- | --- | --- |
| `0x175105` / `0x17510B` | `0x000DED40` | `E-8` |
| `0x175213` / `0x175217` | `0x000DED40` | `E-8` |
| `0x175269` / `0x17526D` | `0x000DEC40` | `E-8` |

The calculation is `(E - 0x0C - 4 × 4 - 3 × 4) + 0x20 = E - 8`, including the four original saves and the outgoing pushes. The original callee instructions `0xDEC4E` and `0xDED4E` move incoming EAX to EDI (`MOV EDI,EAX`) and `0xDEC53` and `0xDED53` immediately zero the DWORD at `[EDI]`; later paths may write a different DWORD through the same address. Both return with `RET 0x0C`.

The Ghidra C draft represented this output with the unbound pseudo-identifier `&stack0xfffffff0` in all three call expressions. The repair replaces those three uses with `&caller_stack_output_word`, the address of one explicit `undefined4` local. It does **not** create a zero-initialized value, change any helper call argument or branch, fake an extra register input, allocate a guest stack using host `alloca`, or interpret the host pointer as an actual Xbox virtual address. The original function body provenance and `ABI_UNVERIFIED` label remain unchanged. The C11 call expressions are still decompiler **host projections**, not proof of the real Xbox register ABI.
