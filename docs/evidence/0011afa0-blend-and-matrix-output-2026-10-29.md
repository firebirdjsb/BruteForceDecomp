# 0x0011AFA0: bounded blend and matrix output producer connection

Date: 2026-10-29. Scope: source-level C11 operations on observed guest storage spans. Neither full original ABI, 1:1 x87/SSE execution, byte-identical rebuilding, nor a playable native PC game is claimed. The original XBE was not available for new binary authentication in this pass; pinned prior evidence is in [0011afa0 scalar storage](0011afa0-scalar-storage.md).

The original call at 0x0011BC4B pushes two guest argument words: the first quaternion pointer and an existing float32 interpolation ratio. Its original EDX is F+0x64 (the second quaternion); ECX is F+0x40 (four-float output). The existing `FUN_0012b250` C draft constructs a 16-byte temporary, calls the existing `FUN_00233b10` SSE blend and copies four raw DWORDs to ECX. `bf_0012b250_blend_operation` now performs the same bounded C-memory operation with explicit input/output addresses and a four-word snapshot, linking **the real existing `FUN_00233b10` source** rather than a duplicate fake helper. The original entry `FUN_0012b250` remains ABI_UNVERIFIED: this is not a claim that its native register/return/call protocol is implemented.

The documented following `0x002333b0` original EDX points to the object at `self+0x37C`, a nine-float matrix output. The new `bf_002333b0_matrix_operation` reuses the existing C draft's float expressions for that exact 36-byte output. The original-entry wrapper uses the same memory operation, but still lacks explicit original EDX transport for other callers. Both operations are invoked from the already syntax-checked `0x0011AFA0` caller via its proven local quaternion and basis storage.

Tests link the actual `src/main_unclassified/band_0023/0x00233b10.c`, exercising 27 deterministic finite SSE blend cases (including opposite signed quaternions and endpoints) at O0/O2. They compare all 16 output bytes with the real function's result, guard both output ends, and validate quaternion-to-matrix finite values and 36-byte identity output. The previous `0x0011afa0` scalar/storage verifier is updated to require both connected host operations and execute these fixtures. These tests do NOT check x87 precision/status, MXCSR exceptions or original game execution; the original XBE was not re-read. The actual original guest ECX, EDX, stack cleanup and indirect helper effects require deeper ABI work.

C source digests for `0x0011AFA0` and `0x002333B0` are updated in the canonical inventory; original body SHA-256 labels and origin/ABI/behavior fields are preserved. Both were already C11 passing; the baseline 13,633 passing / 61 failing is unchanged until a new complete audit. No assets, original binary, game state or deployment were touched.
