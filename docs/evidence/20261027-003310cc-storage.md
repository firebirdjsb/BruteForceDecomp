## Observations

`0x003310E9 PUSH 0x4B0508` supplies an original data address. The old
`&LAB_004b0508` implied an undeclared host symbol. Other PUSH operands at
`0x0033112F/0x00331142/0x003311BD/0x003311D2` similarly supply raw addresses
`0x004B04AC` and `0x004B0498`. The replacement uses these exact addresses;
it does not declare host key objects, copy data or infer an import prototype.

The two output pointers at `0x00331123` and `0x00331139` are EBP-0x28
and EBP-0x24, exactly four bytes apart. They recur at `0x003311B4` and
`0x003311C9`. The later parity calls explicitly pass the FIRST pointer and
length `0x18`, and the table-building calls pass that same first pointer.
The old four-byte object plus unrelated twenty-byte array could not express
the shared storage and overlap. One uninitialized 24-byte array now supplies
base and base+4. No output length or writes of XcHMAC are assumed; no bytes
are synthesized or cleared. The retained platform calls still own outputs.

CBC receives EBP-0x0C at `0x00331169/0x003311F9`. The adjacent words at
EBP-0x0C and EBP-0x08 are now a contiguous `uint32_t[2]`, rather than
independent scalar objects passed as a multi-byte region. The original loads
at `0x00331113/0x0033111B` read `0x004B02C8/0x004B02CC` each iteration.
These are retained as DWORD memory loads, without embedding their contents.

At `0x0033119D`, ECX loads a DWORD from `0x004B04FC`. At `0x003311A3`,
EAX loads one DWORD from the import slot `0x00386464`; only then is the
first word stored at EBP-0x0C. The second word is loaded from `0x004B0500`
and stored at EBP-0x08. The source keeps this read/store order and loads the
import slot once. `MOV ESI,EAX` at `0x003311C2` preserves the imported
address across the first call, and `PUSH ESI` at `0x003311D0` reuses it for
the next call. The replacement does not dereference the key data or reload
the import slot between those calls. The prior `code *` pseudo-type is not
treated as evidence of a callable function or host import object.

The 384-byte table buffer, loop, original entry signature and original body
label remain. New casts express observed guest address operands for source
inspection. They do not implement translation into a native guest-memory map.
