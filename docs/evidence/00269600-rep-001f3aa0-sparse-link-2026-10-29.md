## Original 0x00269600 instruction sequence

Disassembled against the private original XBE; raw instruction patterns are
pinned in `scripts/verify_00269600_guest_rep_xbe.py`.

| Original VA | Guest CPU operation |
| --- | --- |
| 0x00269600–0x00269610 | PUSH EBP / MOV EBP,ESP / AND ESP,-8; EAX=0x14B4; CALL 0x002EBEA0 |
| 0x00269610–0x0026961B | PUSH old EBX, EBX=incoming ECX, read EDX=[EBX+0x514] **before** PUSH ESI/EDI |
| 0x0026961D | MOV [ESP+0x58],ECX, where ECX=original EDX |
| 0x00269621–0x00269627 | XOR EAX,EAX; EDI=ESP+0x10; REP STOSD, ECX=EDX |
| 0x00269629–0x0026963C | ECX=0x146; ESI=EBX; EDI=ESP+0x578; REP MOVSD |
| 0x0026963E onward | Pushes, local writes, CALL 0x00269870, per-element x87 FCOMP/FDIV/FSTP, CALL 0x0026A780, CALL 0x0026A810 |
| 0x002696E0–0x002696EF | ESI=returned EAX; EDI=[EBP+8]; ECX=0x146; REP MOVSD to caller output |

**Aliasing that cannot be optimized away:** for forward `REP STOSD`
(count greater than eighteen), element 18 overwrites the earlier
`[ESP+0x58]` count word with zero. The original count remains in EDX.
With DF=1, a backward write of three or more words reaches the
previously pushed saved EBX/ESI/EDI words. Forward `REP MOVSD` may
propagate overwritten source words when its ranges overlap, unlike
`memmove`. Source fetch and destination write remain distinct guest
memory callbacks. On fault, a repeated instruction retains its current
ESI/EDI/ECX value with the already completed iterations committed.

## 0x001F3AA0 exact sparse source-offset derivation

Caller: AND ESP,-16, EAX=0x20A8, CALL original 0x002EBEA0,
then PUSH ESI and PUSH EDI. CALL 0x002B7970 follows two temporary
PUSH arguments and **callee RET 8 at 0x002B7AED**; CALL 0x002B8D60
returns with **plain RET at 0x002B8DD9**.

Therefore at `0x001F3B4A`,
`live_esp=(guest_EBP & ~15)-0x20B0`.
The 256 forward DWORD writes at 32-byte strides run from
`(guest_EBP & ~15)-0x2000` through
`(guest_EBP & ~15)-0x20`.

- `src/guest_cpu/bf_001f3aa0_sparse_site.h` checks the observed
  live guest ESP against this original relationship before invoking
  the prior sparse write operation.
- `tests/test_001f3aa0_sparse_site.c` validates 32 guest EBP
  alignments, 256 untouched interstitial regions and invalid ESP
  refusal (33,024 assertions per optimization setting).
- Focused CI passed in run `40971303024`.
- `scripts/verify_002ebea0_guest_chkstk_xbe.py` now fingerprints
  original CALL/RET instructions for both intervening callees.
  All five new fingerprints matched the pinned XBE independently.
