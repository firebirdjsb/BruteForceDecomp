# 0x0026A810 matrix integration and 0x002B7970 x87 vector prefix

2026-10-29, original user-provided Xbox Brute Force XBE:
`b6ea5d4dd6500ae86c3f5e3e4618bc9b1e3facddcb483170dfee7a787087c721`.

**Scope:** instruction-guided, bounded guest-memory C11 operations and
focused CI. Not proof of complete host/Xbox parity or original-source
syntax completion. Original Ghidra draft bodies remain unchanged.

## 0x0026A810: matrix multiplication and raw frame copy

Authenticated original function VA 0x0026A810..0x0026A8F5,
230-byte SHA-256:
`8b28ca66b84826c0bbce3323287a85c919ba60d41f1d3c3c87f2c517eedcbc81`.

- The original procedure takes output, left matrix and right matrix in
  its three guest stack arguments. Left row count is a guest DWORD
  at [left+0x510], dot-product term count at [left+0x514],
  and right column count at [right+0x514].
- It enters with `SUB ESP,0x528`, saves original ESI/EDI and, when
  applicable, EBX/EBP. The x87 multiply-add path reads the initial
  m32fp accumulator at `0x003A4F88` then repeats
  `FLD m32fp [right]; FMUL m32fp [left]; FADDP ST(1),ST`
  and finishes with `FSTP m32fp`. The original count-zero path stores
  an explicit zero rather than reading the global accumulator.
- Data-driven row/column counters and the EBX frame offset are
  **reloaded from guest stack storage**, not cached as immutable host
  locals. This is necessary when guest addresses alias or are modified.
- Original `REP MOVSD` at 0x0026A8EB copies **0x146 raw DWORDs**
  from `entry_ESP-0x518` to the output address. It includes
  uninitialized words, as well as original row metadata DWORDs
  at `entry_ESP-8` and `entry_ESP-4`.
  It is direction-flag aware; guest source/destination reads/writes
  remain separate operations and support partial-fault observation.
- It restores guest registers and returns using the original guest
  return DWORD rather than inferring a host C return address.

`src/guest_cpu/bf_0026a810_guest_matrix.h` contains the execution
bridge; all 80-bit arithmetic and exception handling is deliberately
delegated to explicit x87 backend callbacks.

`src/guest_cpu/bf_00269600_combine_call.h` reconstructs the actual
caller `0x002696C3..0x002696E0`: three PUSHed argument addresses,
CALL-pushed continuation at 0x002696E0, and the three input-object
pointers relative to the original live S/ESP. It validates that
the callee restores guest ESP and yields its expected guest EIP/EAX
output. Tests also check a genuinely overlapping output/RET slot
rather than pretending host memcpy can reproduce it.

Focused CI run `40978978497` passed
**100,480 matrix assertions and 2,397 caller-integration assertions**
at both `-O0` and `-O2` plus ASan/UBSan.
The regression added a nonzero x87 seed to ensure arithmetic uses
the original guest global and does not assume zero. Original XBE
whole-image hash, function hash and 43 machine-code windows are checked
by `scripts/verify_0026a810_guest_matrix_xbe.py`, run locally with
the private XBE (no original executable bytes in GitHub).

## 0x002B7970: pre-SSE x87 vector construction

`src/guest_cpu/bf_002b7970_guest_base.h` reproduces the original
guest-memory operations from `0x002B7970` through the instruction
before `0x002B7A2D`. This includes:

- Two original writes of vtable VA `0x0039EFB8`.
- Original object DWORD zero stores and raw 3-float vector copies.
- Three separate `FLD; FLD; FXCH ST(1); FSTP; FSTP` sequences,
  with read-before-write ordering and x87 store callback ownership.
- Explicit per-access guest memory and fault positions; no native
  host pointer is created from Xbox guest addresses.
- Preservation of the `destination+0x0C` word until the later
  SSE-tail cleanup at `0x002B7AE3`. Zeroing it early would change
  original instruction side effects and fault semantics.

`tests/test_002b7970_guest_base.c` passed **37,425 assertions**
at `-O0` and `-O2`, plus ASan/UBSan, in focused CI run
`40979340598`. The tests use raw float words as a bounded
reference; they do not claim NaN conversion, x87 status/precision
or Xbox SEH equivalence.

**Remaining in 0x002B7970:** the `FLD/FMUL/FSTP` scalar operation,
the two SSE `MOVSS/MOVHPS/SHUFPS/MULPS/ADDPS` sequences and their
lane-1 preservation/exception semantics, final output zero writes and
`RET 8`. The current helper is intentionally not named as a full
function reconstruction or wired into the original
`FUN_001F3AA0` body yet.

## Current project boundary

The last published whole-tree *isolated Clang syntax* result remains
**13,636 passing of 13,694 (99.58%), 58 failing** with no original
instruction/body provenance mismatches. The new guest bridges alone
do not credit the original `FUN_00269600` or
`FUN_001F3AA0` with new syntax passes. Xbox register ABI,
SSE/MXCSR/x87 control word, guest SEH and native cross-function linkage
are separate outstanding verification requirements.
