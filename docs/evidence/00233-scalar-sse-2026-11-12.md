# Retail scalar SSE operations at 0x00233020 and 0x002331F0

The original retail XBE authenticated to
`B6EA5D4DD6500AE86C3F5E3E4618BC9B1E3FACDDCB483170DFEE7A787087C721`.
The two complete function bodies are 303 and 152 bytes. Their original
addresses and digests are preserved in the canonical sources and verifier.

- Both routines load a binary32 word, clear its sign bit with the mask at
  `0x0038D910`, scale it by the word at `0x0038D8E0`, and use the original
  `CVTTSS2SI` / `CVTSI2SS` sequence. Index parity selects the folded scalar.
  The original `SHL` and `ORPS` reinsert the appropriate sign bit without a
  floating-to-integer numeric cast.
- The polynomial uses four raw binary32 coefficients at
  `0x0038D950..0x0038D95F`. The paired entry keeps the observed interleaving
  of scalar operations. Its third stack output is written before its second,
  including when the addresses overlap.
- `0x002331F0` computes a binary32 result and then loads it into x87 ST(0).
  The GNU/Clang binary80 wrapper performs `FLD m32fp`. Hosts whose
  `long double` is binary64 retain the existing host numeric projection.
- The three E8 sites in `0x00212280` use the canonical float interface.
  The three sites in `0x002336D0` push the original first-argument DWORD
  unchanged, so their draft uses the captured-word interface directly.
  The matrix arithmetic and register inputs in these two callers remain
  under `ABI_UNVERIFIED`.

`python3 tools/check_cpp_00233_scalar_sse.py` runs all four strict C++17
syntax checks and the public bit-pattern and overlap fixture at `-O0` and
`-O2`. With `--xbe` on Linux x86, the verifier reads the private original
image, checks four complete body hashes, all six direct CALL targets and the
original constants, and runs the two authentic routine bodies in a
freestanding i386 harness. The original bytes are extracted into a temporary
directory for that run.

At each optimization level, 65,936 input/control cases agreed for the
output words, output aliasing, MXCSR, and the single routine's binary80
ST(0) result and defined x87 status bits. The cases cover the four rounding
modes with all DAZ and FTZ combinations, seeded sticky flags, signed zero,
subnormals, infinities, NaNs and conversion boundaries. This covers captured
words, mapped native output storage, masked floating-point exceptions and
an initially empty x87 stack. Guest pointer translation, original XMM
register transport, unmasked traps, guest stack effects, full-game linkage
and binary64 host ST(0) behavior remain unverified.
