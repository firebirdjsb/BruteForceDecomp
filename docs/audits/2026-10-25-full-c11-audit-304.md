## Evidence-backed source repairs included in this audited commit

- **`src/main_unclassified/band_0029/0x0029f440.c`:** original QueryInterface callback writes an interface into a 32-bit guest stack output slot; the caller invokes its vtable `+0x30` entry and later releases the same returned interface through vtable `+0x08`. The former draft erroneously called a synthetic `pcRam00000030` and confused a file-path pointer with the returned object.
- **`src/main_unclassified/band_0005/0x0005af30.c`:** original negated x87 input and accumulating length remain guest float32 stack values, independent of the original 32-bit destination pointer. Original SSE uses `SQRTSS` and approximate `RSQRTSS`; output float32 lanes are preserved as raw bit patterns rather than numerically cast to integers.

Focused original instruction signatures for these repairs are recorded in `scripts/verify_0005af30_0029f440_x86.py`. It supports optional original-XBE verification, and CI uses source-only checks because the original executable must **not** be committed to the repository.

### Correctness boundaries

- Reconstructed 32-bit guest stack words and pointers remain **guest representation**, not freely dereferenceable host pointers on Windows/Linux/Android.
- x87 stack rounding and full SSE high-lane behavior, all virtual method prototypes, register calling conventions, Xbox SEH, and indirect call resolution are **not comprehensively verified**.
- Function-body hashes certify original disassembly provenance only; **no 1:1 completion percentage** can be inferred from those hashes or Clang.
- Preserve `main` as the single development branch; never rewrite unknown stack references with dummy values to improve the percentages.
- Update README's displayed counts only after a *completed* repository-wide audit of the exact source commit.
