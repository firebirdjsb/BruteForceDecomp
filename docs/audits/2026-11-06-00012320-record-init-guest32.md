# 0x00012320 record initializer: bounded original-XBE C++17 repair

## Identity and evidence boundary

Original retail Xbox XBE SHA-256 is pinned to
`B6EA5D4DD6500AE86C3F5E3E4618BC9B1E3FACDDCB483170DFEE7A787087C721`.
Only the user-owned local file is used; it must **not** be committed or uploaded
as CI source. This batch preserves all 13,694 original-address source files and
the complete original byte-identity labels.

- Original caller/draft `FUN_00012320`: entry `0x00012320`, exactly 125 raw
  original instruction bytes, original SHA-256
  `09DF5F57AB66CA1D79AC7A0FB48234BFAD09EDAA4737F016616473C9F3143917`.
- Direct callee `FUN_0008f6a0`: entry `0x0008F6A0`, exactly 64 original bytes,
  original SHA-256
  `339DC70ADE9DA431A03D8964268E2B983BF89DF209448A87B645006C63D4420D`.
- Original direct `E8` at `0x0001238F` targets `0x0008F6A0`.
- Original `0x0001238E PUSH ECX`, `0x00012389 LEA ESI,[EDI+0x0C]`,
  `0x00012394 ADD ESP,4`, and `0x0001239A RET 4` establish the *single
  stack-word input at that call site* and callee-cleaned stack word at
  `0x00012320`'s return. These facts do not establish host C++ method ABI.
- Within the callee, original `0x0008F6A6 MOV EBX,[ESP+8]` follows `PUSH EBX`;
  original `0x0008F6DF RET` does not clean a callee argument word.
- The initializer writes original guest-virtual-address constants `0x003A479C`
  and `0x003A4F64`, **not** host addresses of similarly named draft symbols.
- Original `MOV BL,BYTE PTR [EDI+0x38]` and `MOV BYTE PTR [EDI+0x38],BL`,
  with `AND BL,0xFE`, and the same sequence for `+0x3C`, are byte operations;
  adjacent bytes must be preserved. A guessed 32-bit read-modify-write is not
  equivalent and is intentionally not used.
- `0x00012397 MOV EAX,EDI` identifies the returned guest value; the host
  function return is still only a **register model**, not a recovered ABI.

## Gates and results

Private XBE-only command:

```bash
python3 scripts/verify_20261106_00012320_xbe.py --xbe /private/path/to/default.xbe
```

Checks whole-file authentication, two complete original-body hashes, 46
selected original opcode/operand windows, the original direct E8 destination,
the original RET 4, and 322 single-byte mutation controls.

Public source-only command:

```bash
python3 tools/test_cpp_20261106_00012320_record_init.py
```

Compiles the real original-address `.cpp` with Clang++17 at O0 and O2. An
isolated guest-memory mock checks 8,192 input states per optimization for
32-bit wrapping guest addresses, precise byte and DWORD operation order,
call arguments and EAX return, including four intentionally incorrect source
mutations. The callee is a **dispatch observer only** and does not implement
its original effects. No native pointer is converted or truncated to guest32.
Guest byte read/write declarations are deliberately unresolved until a
separately verified guest-address-translation implementation exists.

## Remaining verification levels

`CPP_DRAFT, ABI_UNVERIFIED, CROSS_FUNCTION_UNVERIFIED, NOT_NATIVE_LINKED,
NOT_BEHAVIOR_TESTED`. Xbox incoming EDI and ECX registers are modelled by
explicit *host fixture parameters*; the original Xbox calling convention,
MSVC 32-bit `this` or object layout, indirect caller linkage, guest stack,
actual guest VA memory mapping, flags, callee side effects and full-game
behavior are still unresolved. No C++ class or gameplay meaning is inferred
from the observed instruction addresses or constant values.
