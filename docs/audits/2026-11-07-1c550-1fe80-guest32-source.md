# Two original Xbox guest32 source repairs: `0x0001C550`, `0x0001FE80`

**Evidence boundary:** Both reconstructed `.cpp` files are strict host C++17
**drafts**, not recovered original Xbox C++ method signatures or fully linked,
byte-identical/native gameplay behavior. The pinned source of truth is the
user-owned retail Xbox XBE SHA-256
`B6EA5D4DD6500AE86C3F5E3E4618BC9B1E3FACDDCB483170DFEE7A787087C721`.
The original binary is never committed.

## `FUN_0001C550`: byte-flag chain and live EAX

Original instruction sequence:

- `0x1C550 MOV ECX,[EAX]`; `0x1C552 MOV DL,BYTE PTR [ECX+0xA9]`;
  `0x1C558 TEST DL,DL`; `0x1C55A JNE 0x1C56E`.
- Only on the zero branch, `0x1C560 MOV EAX,ECX` then
  `0x1C562 MOV ECX,[EAX]`, `0x1C564 MOV DL,[ECX+0xA9]`,
  `0x1C56A TEST DL,DL`, `0x1C56C JE 0x1C560`.
- `0x1C56E RET` has no immediate stack cleanup.

The original C draft cast a native pointer to a 32-bit integer. The replacement
uses existing `bf_guest_read_u32` and **byte-width** `bf_guest_read_u8` guest
VA operations, 32-bit wrapping address addition, and preserves the original
read order. A host return explicitly models the outgoing original EAX. The
actual Xbox signature is **not** thereby a `uint32_t` parameter/return pair.
In particular, original ECX, low EDX byte (`DL`), flags, fault timing, full
register/stack ABI and guest mapping are **ABI_UNVERIFIED**. The synthetic
fixture uses terminating, finite chains; behavior of corrupt/cyclic lists is
not proven.

## `FUN_0001FE80`: conditional tail dispatch

Original x86:

```
0x1FE80  MOV EAX,[EDX+4]
0x1FE83  TEST EAX,EAX
0x1FE85  JE 0x1FE8C
0x1FE87  JMP 0x8F6E0
0x1FE8C  RET
```

The host draft uses the **already-existing**
`FUN_0008f6e0(std::uint32_t guest_edx)` guest-register adapter only when the
original DWORD at `[EDX+4]` is nonzero. It does **not** claim the call/return
is an x86 tail-JMP equivalent; original EAX, flags, caller return ownership,
callee effects, and native linkage remain `ABI_UNVERIFIED`.

## Validation

- Private `scripts/verify_20261107_1c550_1fe80_xbe.py --xbe PRIVATE_XBE`:
  whole-XBE authentication, two complete contiguous body SHA-256 checks,
  16 exact original opcode windows, four branch/jump destinations, and
  **88 negative byte-mutation controls**.
- Public `python3 tools/test_cpp_20261107_1c550_1fe80_guest32.py` compiles
  both **actual source translation units** at Clang C++17 `-O0` and `-O2`
  with strict pointer-to-integer warnings; executes **8,192 scenarios per
  function and optimization level** checking observed guest read order,
  return or dispatch values, byte semantics and wraparound. Six wrong-offset,
  loop-condition or dispatch mutations are required to fail.
- Repository-wide source identity, original body-label and C++17-only
  source-audit policy gates were run separately; they are not ABI tests.

**Next evidence requirements:** exact caller live-in/out registers and stack
frame, guest VA translation, target callee ABI/tail-return semantics and
real-game execution comparisons. Neither source earns `BEHAVIOR_VERIFIED`.
