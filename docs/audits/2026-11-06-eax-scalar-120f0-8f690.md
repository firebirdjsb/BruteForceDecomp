# Two bounded Xbox EAX guest32 reconstructions (2026-11-06)

## Authenticated evidence

The privately held original retail Brute Force XBE has SHA-256
`B6EA5D4DD6500AE86C3F5E3E4618BC9B1E3FACDDCB483170DFEE7A787087C721`.
The XBE remains outside Git and is not distributed as part of this change.

| Original entry | Byte count | Original body SHA-256 |
| --- | ---: | --- |
| `0x000120F0` | 71 | `9FEFE68C61CEC0943A913B1988495825BFD1E3F128E1F92DB0A3DA5D8376BB9C` |
| `0x0008F690` | 15 | `A2E7B7D3A7DD6A4F5F264C6DEBD3A89E8588ECA8F90B3ED3FE84637F77145138` |

At `0x0008F690`, the entire original instruction body is exactly `IMUL
EAX,EAX,0x19660D`, `ADD EAX,0x3C6EF35F`, `SHR EAX,21`, `RET`.
The draft now models the incoming EAX guest value explicitly and preserves
32-bit multiplication/addition overflow and *logical* right shift; it no
longer reads an uninitialized host local named `in_EAX`.

At `0x000120F0`, the original guest EAX is dereferenced at offset `+8`. If the
loaded guest DWORD is zero, the original increments EAX by `0x0C`, then loads
from `[EAX+4]`, i.e. original guest EAX `+0x10`. If nonzero, two fresh ESP
scratch words are set to zero, and ESI is loaded from one of those words.
The later read from the same zeroed scratch word makes the conditional
`CALL 0x0008F6E0` at `0x0001212B` unreachable in ordinary non-aliased
execution. The current bounded host model returns zero on this branch rather
than inventing a guest ESP address or host callback. **This is not a proof of
full Xbox stack alias/fault/interrupt equivalence.**

## Verification and boundaries

- Private `scripts/verify_20261106_eax_scalar_drafts_xbe.py --xbe PRIVATE_XBE`
  checks whole-XBE SHA, **two complete original body hashes**, **27 exact
  opcode/operand windows**, **one original E8 CALL destination** and **172
  negative byte/operand mutation controls**.
- Public `python3 tools/test_cpp_20261106_eax_scalar_drafts.py` compiles
  the real two C++17 files at Clang O0/O2, tests 16,384 synthetic inputs per
  function at each optimization level, checks guest-memory read ordering and
  32-bit wraparound, and rejects four wrong-source mutations. The fixture is
  not an original Xbox execution oracle and deliberately does not emulate
  the original machine stack or guest memory mappings.
- Canonical original-address names and original body-hash labels stay intact.
  No host pointer is cast or truncated to 32 bits. Only two original-address
  drafts are changed, and no unknown class or vtable is declared.
- Remaining `ABI_UNVERIFIED`: original entry/exit calling conventions,
  ESP-local aliasing, fault/interrupt behavior, live register preservation,
  callee/linkage contracts and actual original-mode game behavior. A strict
  host syntax pass does not establish 1:1 full-game behavior or an Xbox rebuild.
