# `FUN_00015F80`: original-XBE-backed guest32 record scan

## Provenance and limits

The user-owned original retail `default.xbe` has SHA-256
`B6EA5D4DD6500AE86C3F5E3E4618BC9B1E3FACDDCB483170DFEE7A787087C721`.
The exact **contiguous 38-byte** original function body from
`0x00015F80` to `0x00015FA5` (inclusive) hashes to
`46944BDE93CACAC236E2744F46EC746CA169DC29643CC7D75DE51A78196C9659`.
This matches `metadata/bulk_13694_inventory.csv` and the canonical draft's
original-body label. Only narrowly scoped hexadecimal instruction windows
are retained in the public verifier; the retail executable is not committed.

The original x86 instructions load `EDX` from `[ECX]`, then load a guest end
address from `[EAX+8]` and a guest current address from `[EAX+4]`. If the
range is nonempty, they compare the 32-bit word at current with `EDX` and
advance by 24 guest bytes on mismatch, wrapping at 32 bits. Equality or
exhaustion converges on `XOR EDX,EDX; CMP EAX,ECX; SETE DL; DEC EDX;
AND EAX,EDX; RET`, returning the found address or 0. The instructions do
not establish ownership, an object class, an original C++ method signature,
or safety of arbitrary guest addresses.

The C++17 draft explicitly receives **host-side models of original live-in
EAX and ECX** as `std::uint32_t`; these are NOT reconstructed original Xbox
stack parameters. The existing `bf_guest_read_u32()` declaration is the
interface boundary for guest-memory access, with no production translation
implementation. It never converts a native host pointer into a guest32 VA.

## Verification

- `python3 scripts/verify_20261107_00015f80_xbe.py --xbe PRIVATE/default.xbe`
  authenticates the entire XBE, checks the 38-byte original-body SHA-256,
  verifies **17 complete instruction windows**, **3 branch destinations**,
  and rejects **79 byte/target mutation controls**.
- `python3 tools/test_cpp_20261107_00015f80_guest32_scan.py` compiles the
  actual canonical `.cpp` translation unit with strict Clang++17 at `-O0`
  and `-O2`. An independent x86-order guest-memory oracle checks **8,192
  bounded synthetic scenarios per optimization level** for reads and return
  values, including empty ranges, successes, misses, alias cases and 32-bit
  address wrap. Five wrong-operand/stride comparisons are deliberately
  changed and required to fail. A finite read budget prevents an incorrect
  stride from making the negative control hang.
- Canonical address/path and body digest provenance are not modified.

## What is NOT verified

`CPP_DRAFT, ABI_UNVERIFIED, NOT_NATIVE_LINKED, NOT_BEHAVIOR_TESTED`.
The harness does not validate real guest VA allocation, fault ordering,
all GPR/flags outputs, external callers, Xbox object layout, full cross-
function linkage or gameplay behavior. A host syntax pass or an isolated
synthetic memory match is not a 1:1 executable or byte-identical rebuild.
